# Echo — MVP Telegram-бота-планувальника нагадувань

## Структура

```
echo-bot/
├── database.py      # aiosqlite: схема + CRUD (users, chats, reminders)
├── bot.py            # Aiogram 3.x: /start, /app, обробка чатів і inline-кнопок, планувальник
├── api.py            # FastAPI: статика Mini App + REST API для CRUD нагадувань
├── main.py            # Запускає бота і API разом в одному процесі
├── static/index.html  # Telegram Mini App (чистий HTML/CSS/JS, теми Telegram)
├── requirements.txt
└── .env.example
```

## Запуск локально

1. Встановіть залежності:
   ```
   pip install -r requirements.txt
   ```

2. Скопіюйте `.env.example` у `.env` і заповніть:
   - `BOT_TOKEN` — токен від [@BotFather](https://t.me/BotFather)
   - `WEBAPP_URL` — публічна HTTPS-адреса вашого `api.py`.
     Telegram Mini App **не відкриється** по `http://localhost`,
     тому для локальної розробки прокиньте порт назовні, наприклад через ngrok:
     ```
     ngrok http 8000
     ```
     і встановіть видану адресу (`https://xxxx.ngrok-free.app`) як `WEBAPP_URL`.

3. У @BotFather виконайте `/mybots` → ваш бот → `Bot Settings` → `Menu Button` (або `Configure Mini App`)
   і вкажіть ту саму адресу `WEBAPP_URL` — тоді Mini App відкриватиметься і кнопкою меню.

4. Запустіть усе одразу:
   ```
   python main.py
   ```
   Це підніме і long-polling бота (разом з фоновим планувальником, що перевіряє
   нагадування кожні 30 секунд), і FastAPI на порту з `API_PORT` (за замовчуванням 8000).

5. У Telegram напишіть боту `/start`, потім тисніть кнопку «Відкрити Echo» або `/app`.

## Що вже працює в цьому MVP

- Реєстрація користувача та його "особистого" чату при `/start`.
- Автозбереження групи/каналу як маршруту відправки, коли бота туди додають.
- CRUD нагадувань через API (`/api/reminders`), яким користується `index.html`.
- Вибір маршруту відправки (особисті / група / канал) у формі створення.
- Опціональні тумблери **Snooze** (кнопка «Відкласти на 15 хв») і **Трекер**
  (кнопка «Виконано» + лічильник стріку) — рендеряться як inline-кнопки під повідомленням.
- Поле для URL картинки — якщо заповнене, нагадування надсилається як фото з підписом.
- Фоновий APScheduler-джоб, який раз на 30 секунд перевіряє й відправляє нагадування.

## Що варто зробити далі (наступні ітерації)

- Повторювані нагадування (щодня / щотижня), а не лише разові.
- Реальна перевірка, що бот дійсно адмін у групі/каналі (зараз зберігаємо будь-яке додавання).
- Пагінація списку та статистика по стріках на окремому екрані.
- HTTPS-деплой (Render/Fly.io/VPS + Caddy) замість ngrok для продакшна.
